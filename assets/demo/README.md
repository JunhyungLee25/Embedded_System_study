# Demo Assets

Place the final result demo videos here.

Recommended filenames:

```text
led-control.mp4
counter-control.mp4
```

The root `README.md` links to these paths:

```text
assets/demo/led-control.mp4
assets/demo/counter-control.mp4
```

Video descriptions:

- `led-control.mp4`: LED control demo for `05_Device_Driver_02`. The LED turns on/off when a button or keyboard input is pressed.
- `counter-control.mp4`: Counter control demo for `03`.
